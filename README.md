# GHOSTWIRE

**GHOSTWIRE** is a browser-based cinematic terminal simulator inspired by the gloriously unrealistic computer interfaces of sci-fi and hacker movies.

It combines procedural terminal output, randomized typing behavior, visual anomalies, directional data streams, localized code fields, and plenty of nerd-culture Easter eggs to create the illusion of some **deep, questionably comprehensible hacking happening under the hood.**

## Features

* Procedurally generated terminal activity
* Old-school typewriter output and block cursor
* Variable processing and typing speeds
* Multi-layer visual effects
* Directional code/data streams
* Moving localized code fields
* Screen flashes and system anomalies
* Fullscreen mode
* Adjustable speed and chaos
* Randomized sci-fi/hacker Easter eggs
* Runs entirely in your browser

## Run It

No installation or server is required.

Download the project and open:

`index.html`

in a modern browser.

## Important

GHOSTWIRE is **purely a visual simulation**.

It does not scan your network, inspect devices, access remote systems, or perform any actual hacking.

It just looks suspiciously busy doing absolutely none of those things.
